# 第四面牆 AI

## 重塑現場管理：讓真實空間具備感知、追蹤與協作能力

透過無人機、固定攝影機與 AI Agent 的無縫整合，為工廠與工地打造專屬的 Digital Twin，實現即時通報、精準追蹤與歷史回放的智慧大腦。

## 我們解決的問題

- 現場資訊分散：影像、巡檢紀錄、異常事件與人員回報散在不同工具，管理者很難建立同一套現場事實。
- 異常發現太晚：問題常等到人工巡檢或事故發生後才被注意，缺少持續運作的早期提醒。
- 遠端掌握困難：老闆與主管需要在不進場的情況下，快速理解工地與工廠目前最重要的狀態。
- 經驗難以累積：現場判斷依賴資深人員與口頭交接，缺少可追蹤、可回查、可協作的營運資料。

## 服務內容

### 智慧工地巡檢與風險管理

整合工地影像、無人機或手機巡檢資料，辨識安全帽、危險區域、洞口、材料堆置與施工異常，並把事件標記在 3D / 平面圖上。

### 日常營運的虛擬工廠 Digital Twin

用固定攝影機與 3D 場域模型追蹤設備、儀表板與工作區域狀態，讓主管遠端掌握工廠現況，並由 LINE 群組 AI 助手主動提醒。

### LINE / Web 通報與事件追蹤

事件建立、確認、指派、處理中與結案都能形成可回查紀錄，未來可接群組 quick reply 與現場回報。

## 4WALL Industrial Data Engine

讓現場管理平台從「看見現場」進一步走向「理解現場」。

第四面牆的現場管理平台整合影像、巡檢紀錄、Digital Twin、異常事件與處理流程。為了讓 AI 更穩定地辨識危險區入侵、通道阻塞、漏水、冒煙、儀表板異常與人員靠近高風險區域，我們正在建置平台底層的 AI 訓練資料與模型驗證引擎。

### 現場影像很多，異常資料很少

工業現場每天累積大量正常影像，但真正重要的異常事件發生頻率低、蒐集困難，也不適合為了訓練模型刻意製造事故。

資料引擎支撐現場事件辨識的流程：

1. 生成工業場景：建立工廠、機台區、通道與設備區等場景。
2. 模擬異常事件：產生冒煙、漏水、危險區入侵、通道阻塞等稀有事件。
3. 自動產生標註：產出影像、事件標籤、mask、bounding box 與 metadata。
4. 訓練巡檢模型：在真實資料不足時，持續驗證與優化事件辨識模型。

底層資料能力回到現場管理價值：

- 補足稀有異常資料：不必等待事故真的發生，也能建立模型訓練資料。
- 降低標註與導入成本：自動產生影像、事件與標註資料，減少前期資料準備時間。
- 強化現場事件辨識：讓第四面牆平台從看見現場，進一步理解現場。

## 系統流程

1. 建立場域模型
2. 接入攝影機 / 無人機
3. AI 分析影像與事件
4. 呈現 3D / 平面圖 / 事件卡
5. LINE / Web 通知
6. 累積營運資料庫
