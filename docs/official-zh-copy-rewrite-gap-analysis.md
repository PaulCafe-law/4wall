# `/official` 中文官網文案重寫 Gap Analysis

日期：2026-07-26

## 目標與讀者

本次重整公開官網 `/official` 的繁體中文文案與 Hero 封面圖片，主要讀者為台灣中小型製造業老闆、廠長與製造主管、系統整合商，以及新創加速器與投資人。英文版 `/official/en`、主要路由、登入與管理平台功能不在修改範圍內。

中文版要將產品核心從「3D 展示、LINE 問答與攝影機辨識」提升為：

> 協助工廠匯出並整合分散的機台資料，由工廠地端 AI 持續分析設備與生產狀態，提供稼動率改善與生產排程調整依據，並逐步建立可回查的產品履歷。

## 現行實作來源

- `web-app/src/features/official/OfficialSitePage.tsx`
  - `/official` 與 `/official/en` 共用的版面元件。
  - 頁面順序、區塊 ID、Hero 圖片來源與互動行為都在此檔案中。
- `web-app/src/features/official/officialContent.ts`
  - `zh` 與 `en` 兩份內容物件。
  - 中文首頁的導覽、Hero、功能、流程、案例、價格、導入、資料保護、聯絡資訊與圖片替代文字都來自 `zh`。
- `web-app/src/features/official/useOfficialSiteMeta.ts`
  - 依語系將 `officialContent` 的標題與描述寫入網頁 metadata。
- `web-app/index.html`
  - 首次載入與預先渲染前使用的中文版 SEO 描述及結構化資料。
- `web-app/public/official.md`、`web-app/public/llms.txt`
  - 搜尋引擎與 AI crawler 使用的中文版產品說明。
- `web-app/src/features/official/OfficialSitePage.test.tsx`
  - 中文與英文官網的內容、路由、metadata、圖片尺寸與連結回歸測試。

## 主要落差

1. 第一屏以抽象的問答式標語開場，沒有在第一時間說明資料來源、LINE 查詢、主動通知與實際部署。
2. 第一屏與功能區把 3D、LINE、攝影機與儀表辨識放在產品核心，沒有交代機台資料整合、工廠地端 AI、稼動率、排程與產品履歷。
3. 多處使用沒有清楚主詞的短句，以及「收進一座工廠」「替你值班」「先開口」等抽象比喻。
4. 導覽名稱依賴前後文，訪客無法直接判斷區塊內容。
5. 功能卡片混用技術語氣、口語和英文名詞，沒有穩定呈現「功能與結果」。
6. 現行流程只描述通知、查詢與派工，沒有完整說明再次確認及產出紀錄。
7. 案例與導入文案使用不自然的部署與 LINE 通知用語，不符合台灣製造業常用語。
8. `Spatial OS`、`Industrial Data Engine`、HMI、UWB 與 AMR 缺少第一次出現時的中文說明。
9. 專案內的 `hero-field-ai.webp` 是施工場景；目前 Hero 使用的 `warroom-live.webp` 雖為平台畫面，仍會讓第一印象偏向 3D 展示與 LINE Bot。
10. Hero 圖片替代文字使用偏離產品核心的控制中心稱呼，且描述過長。
11. `index.html`、`official.md` 與 `llms.txt` 仍保留舊敘事，會讓搜尋結果與實際頁面不一致。

## 修改邊界

- 保留所有正式數字、價格、案例名稱與合作單位。
- 將 `zh` 內容改為自然的台灣繁體中文，維持原資料結構，避免影響共用元件。
- 將功能卡片由四項調整為五項核心能力，沿用既有卡片元件與設計系統。
- Hero 改用靚程工廠攝影機取得的實際射出成型產線畫面；既有平台畫面移至案例區，避免重複使用與錯誤定位。
- 同步更新中文版 metadata、crawler 文件及中文測試期望值。
- 不修改 `en` 內容物件，也不更動 `/official/en` 的測試內容。
- 不處理管理平台其他頁面中的既有用詞；禁用詞驗證以 `/official` 正式內容來源及輸出為準。

## 目標敘事

頁面維持現有區塊結構，文案依序傳達：

1. 工廠資料散落在不同機台、PLC、HMI、紙本與人員經驗中。
2. 4WALL AI（第四面牆）協助匯出、整理並統一不同來源的現場資料。
3. 工廠地端 AI 持續分析運轉、待機、停機、異常與生產進度。
4. 系統協助找出稼動率損失，並提供生產排程調整依據。
5. 每批產品的機台、參數、事件與處理結果持續累積成產品履歷。
6. 異常發生後，系統通知負責人、協助指派、再次確認並留下紀錄。
7. 台南射出成型工廠已完成實際部署。
8. 客戶可接著了解導入方式、方案費用與資料保護。
9. 最後引導客戶預約到廠評估。

- 中文官網正式內容來源已確認不含本次禁用的舊標語與用詞。管理平台其他頁面的既有名稱不在本次修改範圍內。
